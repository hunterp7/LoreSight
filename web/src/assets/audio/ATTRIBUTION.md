# Bundled binaural audio

These files are stored locally so LoreSight playback does not depend on a third-party host. All files are MP3 transcodes provided by Wikimedia Commons. Binaural effects require stereo headphones and should be played at a low or moderate volume.

`mixkit-classic-click-1117.wav` is a user-supplied local UI sound effect, used for LoreSight's physical CRT control feedback.
